# Polyglotte

Conservatoire de code : apprendre TypeScript + React, PHP, Java et Python en parallèle, notion par notion.

## Méthode

- Chaque notion est d'abord apprise en TypeScript, la référence.
- Elle est ensuite transposée dans un autre langage par jour : PHP → Java → Python.
- React est travaillé à part : petits composants et front du Répertoire.

## Structure

- `gammes/` : exercices courts (10 min max), un dossier par langage.
- `repertoire/` : projet fil rouge. Front en React + TS, et la même API en Express, Symfony, Spring Boot et FastAPI, décrite dans `contrat-api.md`.

## Outils

Node 26 · TypeScript 7 · PHP 8.5 · Java 25 · Python 3.14
