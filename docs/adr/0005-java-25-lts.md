# 5. Java 25 LTS (Eclipse Temurin)

- Date: 2026-10-12
- Status: Accepted

## Context
Java 8 was installed; Spring Boot requires Java 17 or later.

## Decision
Use Eclipse Temurin 25, the current long-term support release, installed with Homebrew.

## Consequences
Compatible with Spring Boot and with the OCP Java SE 25 certification.
