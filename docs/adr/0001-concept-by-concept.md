# 1. Learn concept by concept

- Date: 2026-10-12
- Status: Accepted

## Context
Four languages are learned in parallel, with 20 minutes to 2 hours a day.

## Decision
Learn each concept once in TypeScript, then transpose it into PHP, Java and Python, instead of learning one language after another.

## Consequences
Immediate comparison and better retention. Risk of mixing syntaxes, limited by TypeScript as the reference and one comparison table per concept.
