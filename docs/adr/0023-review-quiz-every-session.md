# 23. A review quiz at the start of every session

- Date: 2026-11-09
- Status: Accepted (complements 0018)

## Context
A review block every fifth session leaves long gaps; research on retrieval practice shows that recalling beats rereading, and that spaced recall beats massed recall.

## Decision
Every session opens with a six-question quiz (three on the previous session, three on older ones), with a hint per question and a flashcard mode. Sessions 05, 10, 15… keep a larger review: rewriting an exercise from memory or a mock exam.

## Consequences
About five minutes per session; concepts are recalled just as they start to fade.
