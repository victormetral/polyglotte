# 22. Rust as a reading voice

- Date: 2026-10-24
- Status: Accepted

## Context

A teacher encouraged starting Rust early; motivation is high, but the four languages, React, Linux and algorithms already fill each session, and work-study starts in February 2027.

## Decision

From session 04, each scale shows the same concept in Rust, read and compared only: no installation, no files. Turning Rust into a small practice voice (scales only, in scales/rust/) is examined at the end-of-January review.

## Consequences

Early exposure to Rust's model (ownership, memory safety) at almost no cost; the four main voices stay protected. Complements ADR 0009, which keeps Go as the first new language after the CDA.
