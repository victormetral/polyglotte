# 2. Transposition order: TypeScript, PHP, Java, Python

- Date: 2026-10-12
- Status: Accepted

## Context
The order in which a concept is transposed shapes how hard each step feels.

## Decision
Go from the syntax closest to TypeScript to the most distant: PHP, then Java, then Python.

## Consequences
PHP consolidates the concept, Java reuses the types seen in TypeScript, Python comes when the concept is solid.
