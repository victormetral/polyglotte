# 18. Frozen decisions, quarterly reviews, review blocks

- Date: 2026-10-20
- Status: Accepted

## Context
Changing decisions mid-way was costing time.

## Decision
Validated decisions are frozen and reviewed only at the end of January, April, July and October; every fifth session includes a review block.

## Consequences
Fewer back-and-forths; new ideas wait for the next review.
