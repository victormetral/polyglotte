# 15. Tooling per language

- Date: 2026-10-20
- Status: Accepted

## Context
Each language needs one package manager, test runner and checker, chosen once.

## Decision
npm, Vitest, tsc, ESLint, Prettier; Composer, PHPUnit, PHPStan, PHP-CS-Fixer; Maven, JUnit 5, Spotless; uv, pytest, mypy, Ruff; ShellCheck; one .editorconfig.

## Consequences
No tooling debates later; Java becomes a Maven project at session 08.
