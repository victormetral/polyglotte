# 10. Flexible sessions with every voice

- Date: 2026-10-19
- Status: Accepted (supersedes 0003)

## Context
Available time varies from 20 minutes to 2 hours a day.

## Decision
A session is defined by its content (scale in four languages, React etude, Linux, algorithm, closing), not by its duration; it can span several days.

## Consequences
No fixed weekdays; every voice keeps the same session number, and a lagging voice is caught up first.
